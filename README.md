# RNN_3-RNN-for-Time-Series-Prediction
This notebook explores RNN implementation for time-series prediction using Python and TensorFlow/Keras. It covers sequence preparation, sliding windows, model building, training, evaluation, and visualization. Students experiment with sequence lengths and hidden units to understand their impact on predictive performance using Google Colab.

## Topics Covered
- Sequential data preparation
- Sliding-window generation
- RNN architecture and model building
- Model training and validation
- Prediction and performance evaluation
- Visualization of actual and predicted values
- Experimentation with sequence lengths and hidden units

## Learning Outcomes
By completing this notebook, students will be able to:
- Prepare time-series data for RNN-based prediction.
- Build and train a SimpleRNN model using TensorFlow/Keras.
- Evaluate model performance using suitable metrics.
- Visualize and interpret prediction results.
- Explore how sequence length and hidden units influence predictive performance.

## Tools and Technologies
- Python
- TensorFlow/Keras
- NumPy
- Matplotlib
- Google Colab

## How to Use
1. Open the notebook in Google Colab.
2. Select **File → Save a copy in Drive**.
3. Execute the code cells sequentially.
4. Observe the training results and prediction plots.
5. Complete the experiments and reflection activities.
